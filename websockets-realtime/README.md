# 🌐 WebSockets & Real-Time Apps

Build live dashboards, chat, and collaborative features with WebSockets and Socket.io. This tutorial covers events, rooms, presence, scaling, and a capstone support chat.

## What you'll learn

- HTTP polling vs WebSocket push
- Socket.io handshake, events, and rooms
- Building a real-time group chat with typing indicators
- Live dashboards with broadcast metrics
- Presence and scaling with Redis adapter
- Authentication, rate limiting, and production practices
- Capstone: live support chat with message history

## Quick Start

```bash
cd websockets-realtime
npm install express socket.io
node server.js
```

Open `http://localhost:3000` in two browser tabs and chat.

## Recommended prerequisites

- [Node.js & Express](../nodejs-express/)
- [Redis & Caching](../redis-caching/)
