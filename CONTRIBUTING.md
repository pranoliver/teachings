# Contributing to Teachings

Thank you for your interest in improving this collection of interactive tutorials.

## How to contribute

1. **Fork the repository** and create a new branch for your changes.
2. **Keep tutorials self-contained.** Each tutorial lives in its own folder with `index.html` and `README.md`. It should work when opened directly in a browser.
3. **Match the existing style.** Use Tailwind CSS via CDN, the Outfit font, and the same sidebar/dark mode/copy-code/quiz structure used by other tutorials.
4. **Add real-world examples.** Tutorials should include practical commands, diagrams, and a capstone project.
5. **Update root files.** If you add a new tutorial, update `index.html` and `README.md` in the project root to include it.
6. **Test your changes.** Open the affected HTML files in a browser and verify links, code highlighting, and quizzes work.
7. **Submit a pull request** with a clear description of what you changed and why.

## Content guidelines

- Write for beginners, but do not oversimplify.
- Keep code snippets copyable and runnable where possible.
- Add a "Before you start" box and "More practice ideas" box to new tutorials.
- Use lowercase names for favicons in `assets/favicons/`.
- Ensure each tutorial has a unique number in the root listing.

## Questions?

Open an issue if you are unsure about a change before submitting a pull request.
