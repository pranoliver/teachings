AI Agents: Multi-Agent Systems

AI-5

Introduction to AI Agents

A single large language model can answer questions, but it struggles to reason, act, and verify across many specialized domains. An AI agent system breaks work into smaller pieces: a router decides who should act, specialist agents call tools, and a supervisor verifies each step. In this tutorial you will build a multi-agent support system for Nimbus Cloud Solutions using LangGraph, local Ollama models, and Streamlit.

What you will build

  • A single tool-calling agent that can look up account balances.
  • A LangGraph multi-agent pipeline with router, billing, technical, security, and escalation agents.
  • A supervisor approval gate between every stage.
  • An MCP server that exposes the same tools to any client.
  • A Streamlit command center where you can watch agents route and act in real time.

Agent Concepts

Before wiring agents together, it helps to agree on a few terms. These definitions match the LangGraph way of thinking.

Agent, tool, graph, node

  • Agent : an LLM with a system prompt and access to tools.
  • Tool : a typed Python function the LLM can decide to call.
  • Graph : a state machine that describes which node runs next.
  • Node : one step in the graph. It can be an agent, a tool, or a supervisor gate.
  • State : a shared object passed between nodes, usually containing messages.

Why multi-agent?

One giant prompt trying to handle billing, security, and troubleshooting at the same time is fragile. Specialist agents keep each prompt focused, which improves reliability, makes failures easier to debug, and lets you update one part without breaking the rest.

Single Tool-Calling Agent

The simplest agent has one tool and one job. We will build a Nimbus balance assistant: it reads the user's question, decides whether to call get_account_balance , and returns the result.

Define tools 

from langchain_core.tools import tool

@tool
def get_account_balance(account_name: str) -> float:
    """Return the current balance of a Nimbus account."""
    balances = {
        "checking": 12500.00,
        "savings": 48200.50,
        "investment": 103450.75,
    }
    return balances.get(account_name.lower(), 0.0)

@tool
def list_accounts() -> list:
    """List all Nimbus account names."""
    return ["checking", "savings", "investment"]

@tool
def get_invoice_status(invoice_id: str) -> str:
    """Return the status of a billing invoice."""
    return f"Invoice {invoice_id} is paid."

tools = [get_account_balance, list_accounts, get_invoice_status]

Multi-Agent LangGraph

In a multi-agent system, each agent is a node in a graph. One agent routes the request, then control passes to a specialist. Specialists can call tools and return structured responses. LangGraph manages the state and edges for us.

Define state and router 

from typing import TypedDict, Annotated, Sequence
from langchain_core.messages import BaseMessage
import operator

class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], operator.add]
    category: str
    next: str

CATEGORIES = ["billing", "technical", "security", "account", "escalation"]

llm = ChatOllama(model="kimi-k2.7-code:cloud", temperature=0)

def router_node(state: AgentState):
    prompt = f"""You are a support triage router for Nimbus Cloud Solutions.
Classify the user query into exactly one of these categories: {', '.join(CATEGORIES)}.
Return only the category name, nothing else.

User query: {state['messages'][-1].content}"""
    response = llm.invoke(prompt)
    category = response.content.strip().lower()
    if category not in CATEGORIES:
        category = "escalation"
    return {"category": category, "next": category}

Save as router.py and run: uv run router.py

Specialist agents 

from langchain_core.messages import AIMessage

SPECIALIST_PROMPTS = {
    "billing": "You are a Nimbus billing specialist. Be concise, friendly, and accurate.",
    "technical": "You are a Nimbus technical support engineer. Be concise, friendly, and accurate.",
    "security": "You are a Nimbus security specialist. Be cautious, concise, and accurate.",
    "account": "You are a Nimbus account specialist. Be concise, friendly, and accurate.",
    "escalation": "You are an escalation handler. Acknowledge the issue and promise human follow-up within 24 hours.",
}

def make_specialist_node(category: str):
    def specialist_node(state: AgentState):
        prompt = SPECIALIST_PROMPTS[category]
        query = state["messages"][-1].content
        response = llm.invoke([
            ("system", prompt),
            ("human", query),
        ])
        return {"messages": [AIMessage(content=f"[{category.upper()}] {response.content}")]}
    return specialist_node

billing_node = make_specialist_node("billing")
technical_node = make_specialist_node("technical")
security_node = make_specialist_node("security")
account_node = make_specialist_node("account")
escalation_node = make_specialist_node("escalation")

Save as specialists.py and run: uv run specialists.py

Wire the graph 

from langgraph.graph import StateGraph, END

builder = StateGraph(AgentState)
builder.add_node("router", router_node)
builder.add_node("billing", billing_node)
builder.add_node("technical", technical_node)
builder.add_node("security", security_node)
builder.add_node("account", account_node)
builder.add_node("escalation", escalation_node)

builder.set_entry_point("router")
for cat in CATEGORIES:
    builder.add_edge("router", cat)
for cat in CATEGORIES:
    builder.add_edge(cat, END)

graph = builder.compile()

result = graph.invoke({"messages": [HumanMessage(content="Why was I charged twice?")]})
for msg in result["messages"]:
    print(msg.content)

Save as multi_agent.py and run: uv run multi_agent.py

Supervisor & Human-in-the-Loop

Not every agent decision should run unsupervised. A supervisor pauses the graph after a high-impact step, shows the current state, asks for approval, and logs the decision before continuing.

Supervisor as a LangGraph interrupt 

from langgraph.types import interrupt
import json

def supervisor_node(state: AgentState):
    last = state["messages"][-1]
    payload = {
        "stage": state.get("category", "unknown"),
        "agent_output": last.content,
    }
    print(json.dumps(payload, indent=2))

    # Interrupt and wait for human input
    action = interrupt({
        "question": f"Approve {payload['stage']} response?",
        "payload": payload,
    })

    if action.get("approved"):
        return {"messages": [AIMessage(content=f"Supervisor approved {payload['stage']}.")]}
    else:
        return {"messages": [AIMessage(content=f"Supervisor rejected {payload['stage']}. Escalating.")], "next": "escalation"}

# Resume with Command(resume={"approved": True})
from langgraph.types import Command

# graph.invoke(..., config={...})  # starts
# graph.invoke(Command(resume={"approved": True}), config={...})  # resumes

Save as supervisor.py and run: uv run supervisor.py

Compliance validator 

forbidden_topics = ["password", "secret", "credential"]

def compliance_node(state: AgentState):
    text = state["messages"][-1].content.lower()
    for topic in forbidden_topics:
        if topic in text and state.get("category") != "security":
            return {
                "messages": [AIMessage(content="Compliance check failed: sensitive topic handled by non-security agent. Escalating.")],
                "next": "escalation",
            }
    return {"messages": [AIMessage(content="Compliance check passed.")]}

Save as compliance.py and run: uv run compliance.py

MCP: Portable Tools

The Model Context Protocol (MCP) separates tools from applications. You can expose Nimbus tools as an MCP server and let any client consume them. This makes your agent tools reusable across chat clients, IDEs, and dashboards.

Expose tools as an MCP server 

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("nimbus-tools")

@mcp.tool()
def get_account_balance(account_name: str) -> float:
    """Return the current balance of a Nimbus account."""
    balances = {"checking": 12500.00, "savings": 48200.50, "investment": 103450.75}
    return balances.get(account_name.lower(), 0.0)

@mcp.tool()
def list_accounts() -> list:
    """List all Nimbus account names."""
    return ["checking", "savings", "investment"]

if __name__ == "__main__":
    mcp.run(transport="sse")

Save as mcp_server.py and run: uv run mcp_server.py

Why expose tools over MCP?

An MCP server decouples your business tools from any single agent framework. The same get_account_balance tool can be consumed by a LangGraph agent, a Claude Desktop plugin, an IDE assistant, or a custom dashboard. The next section shows a realistic client that connects over SSE.

MCP Client over SSE

A production MCP client connects to a running server over HTTP, lists the available tools, and invokes them. This section uses Server-Sent Events (SSE) transport, which is the easiest way to connect a long-lived MCP server to a remote client.

1. Start the MCP server 

# Terminal 1
uv run mcp_server.py

By default FastMCP with transport="sse" serves on http://127.0.0.1:8000/sse . Keep this terminal open.

2. Discover and call tools from a Python client

Create mcp_sse_client.py . It lists tools, prints their schemas, calls get_account_balance and get_recent_tickets , and handles errors gracefully. 

import asyncio
import json
from mcp import ClientSession
from mcp.client.sse import sse_client

SSE_URL = "http://127.0.0.1:8000/sse"

async def main():
    async with sse_client(SSE_URL) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()

            tools = await session.list_tools()
            print(f"Connected. {len(tools.tools)} tools available:")
            for tool in tools.tools:
                print(f"  - {tool.name}: {tool.description}")

            balance = await session.call_tool(
                "get_account_balance", arguments={"account_name": "savings"}
            )
            print("\nBalance result:")
            print(json.dumps(balance.model_dump(), indent=2))

            tickets = await session.call_tool(
                "get_recent_tickets", arguments={"category": "security", "limit": 3}
            )
            print("\nRecent security tickets:")
            print(json.dumps(tickets.model_dump(), indent=2))

            try:
                await session.call_tool("nonexistent_tool", arguments={})
            except Exception as e:
                print(f"\nExpected error for unknown tool: {e}")

if __name__ == "__main__":
    asyncio.run(main())

Save as mcp_sse_client.py and run: uv run mcp_sse_client.py

3. Connect the client to an LLM

The next step is to let an LLM choose which MCP tool to call. The client fetches the tool list, converts each schema to a LangChain tool, and passes them to an Ollama model. 

import asyncio
from langchain_ollama import ChatOllama
from langchain_core.messages import HumanMessage
from mcp import ClientSession
from mcp.client.sse import sse_client

SSE_URL = "http://127.0.0.1:8000/sse"

async def mcp_agent(query: str):
    async with sse_client(SSE_URL) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            tools_response = await session.list_tools()

            # Build simple LangChain-style tools from MCP definitions
            langchain_tools = []
            for tool_info in tools_response.tools:
                def make_call(name):
                    async def call(args):
                        result = await session.call_tool(name, arguments=args)
                        return str(result)
                    return call

                from langchain_core.tools import StructuredTool
                langchain_tools.append(
                    StructuredTool.from_function(
                        func=make_call(tool_info.name),
                        name=tool_info.name,
                        description=tool_info.description or "",
                    )
                )

            llm = ChatOllama(model="kimi-k2.7-code:cloud", temperature=0).bind_tools(langchain_tools)
            messages = [HumanMessage(content=query)]
            response = llm.invoke(messages)

            if response.tool_calls:
                for call in response.tool_calls:
                    tool = next(t for t in langchain_tools if t.name == call["name"])
                    result = await tool.ainvoke(call["args"])
                    messages.append(result)
                response = llm.invoke(messages)

            return response.content

Evaluation & Tracing

Agents make a chain of decisions: route, act, validate, approve. When something goes wrong you need to see what happened. This section adds a local JSON tracer and a simple evaluator so you can measure routing accuracy, tool correctness, and end-to-end answer quality without relying on a paid service.

1. Trace every graph run to a local JSONL file 

import json
import time
from pathlib import Path
from langchain_core.callbacks.base import BaseCallbackHandler

TRACE_FILE = Path("nimbus_agent_traces.jsonl")

class LocalTracer(BaseCallbackHandler):
    """Append a JSON line for every LLM start/end and tool call."""

    def _append(self, event_type, data):
        line = {"timestamp": time.time(), "event": event_type, **data}
        with open(TRACE_FILE, "a", encoding="utf-8") as f:
            f.write(json.dumps(line, default=str) + "\n")

    def on_llm_start(self, serialized, prompts, **kwargs):
        self._append("llm_start", {"prompts": prompts})

    def on_llm_end(self, response, **kwargs):
        generations = [g.text for g in response.generations[0]]
        self._append("llm_end", {"generations": generations})

    def on_tool_start(self, serialized, input_str, **kwargs):
        self._append("tool_start", {"tool": serialized.get("name"), "input": input_str})

    def on_tool_end(self, output, **kwargs):
        self._append("tool_end", {"output": str(output)})

Save as tracer.py and import it into graph.py

3. Evaluate routing accuracy on the dataset

Run the router against the 70-example dataset and compare predicted categories with the ground truth. This gives you a concrete accuracy score and a confusion report. 

import json
from collections import Counter, defaultdict
from graph import router_node
from langchain_core.messages import HumanMessage

with open("nimbus_agent_queries.json", "r", encoding="utf-8") as f:
    dataset = json.load(f)

correct = 0
counts = defaultdict(Counter)

for item in dataset:
    state = {"messages": [HumanMessage(content=item["query"])]}
    result = router_node(state)
    predicted = result["category"]
    expected = item["category"]
    counts[expected][predicted] += 1
    if predicted == expected:
        correct += 1

accuracy = correct / len(dataset)
print(f"Router accuracy: {accuracy:.1%} ({correct}/{len(dataset)})")
print("\nConfusion matrix (expected -> predicted):")
for expected in sorted(counts):
    row = dict(counts[expected])
    print(f"  {expected:12}: {row}")

Save as evaluate_router.py and run: uv run evaluate_router.py

4. Evaluate end-to-end answers with an LLM judge

An LLM judge compares each final answer against a rubric: accuracy, tone, and whether the right category was used. This is cheaper than human evaluation and easy to iterate on. 

import json
from langchain_ollama import ChatOllama
from langchain_core.messages import HumanMessage
from graph import graph, CATEGORIES

judge = ChatOllama(model="kimi-k2.7-code:cloud", temperature=0)

def judge_answer(query, answer, expected_category):
    prompt = f"""You are an evaluation judge for a Nimbus Cloud Solutions support agent.
Rate the answer on a scale of 1 to 5 for:
1. Accuracy (does it answer the question?)
2. Tone (is it concise, friendly, professional?)
3. Category fit (is it appropriate for {expected_category}?)

Query: {query}
Expected category: {expected_category}
Answer: {answer}

Return ONLY a JSON object with keys accuracy, tone, category_fit, and overall."""
    response = judge.invoke([HumanMessage(content=prompt)])
    try:
        return json.loads(response.content.strip())
    except json.JSONDecodeError:
        return {"raw": response.content, "error": "parse_failed"}

sample = [
    {"query": "Why was I charged twice?", "category": "billing"},
    {"query": "My API returns 429.", "category": "technical"},
    {"query": "My API key was leaked.", "category": "security"},
]

for item in sample:
    result = graph.invoke({"messages": [HumanMessage(content=item["query"])]})
    final = result["messages"][-1].content
    scores = judge_answer(item["query"], final, item["category"])
    print(f"Q: {item['query']}\nScores: {scores}\n")

Save as evaluate_answers.py and run: uv run evaluate_answers.py

Phase 2: Reusable Nimbus tools

Create tools.py . This file is used by the single agent, the multi-agent graph, and the MCP server. Keeping tools in one module means you never duplicate business logic. 

from langchain_core.tools import tool

ACCOUNTS_DB = {
    "checking": {"balance": 12500.00, "status": "active"},
    "savings": {"balance": 48200.50, "status": "active"},
    "investment": {"balance": 103450.75, "status": "active"},
}

TICKETS_DB = [
    {"id": "T-1001", "category": "billing", "status": "open", "summary": "Double charge on invoice"},
    {"id": "T-1002", "category": "technical", "status": "resolved", "summary": "429 rate limit errors"},
    {"id": "T-1003", "category": "security", "status": "open", "summary": "API key exposed in log"},
]

@tool
def get_account_balance(account_name: str) -> dict:
    """Return the current balance and status of a Nimbus account."""
    name = account_name.lower().strip()
    if name not in ACCOUNTS_DB:
        return {"error": f"Account '{account_name}' not found. Valid accounts: {list(ACCOUNTS_DB)}"}
    return {"account": name, **ACCOUNTS_DB[name]}

@tool
def list_accounts() -> list:
    """List all Nimbus account names."""
    return list(ACCOUNTS_DB.keys())

@tool
def check_invoice_status(invoice_id: str) -> str:
    """Return the payment status of a billing invoice."""
    return f"Invoice {invoice_id.upper()} is paid and closed."

@tool
def get_recent_tickets(category: str = "all", limit: int = 5) -> list:
    """Return recent support tickets, optionally filtered by category."""
    category = category.lower().strip()
    tickets = TICKETS_DB if category == "all" else [t for t in TICKETS_DB if t["category"] == category]
    return tickets[:limit]

@tool
def rotate_api_key(account_name: str) -> dict:
    """Rotate the API key for an account and return a confirmation."""
    name = account_name.lower().strip()
    if name not in ACCOUNTS_DB:
        return {"error": f"Account '{account_name}' not found."}
    return {"account": name, "action": "api_key_rotated", "new_key_prefix": "nb_live_..."}

NIMBUS_TOOLS = [get_account_balance, list_accounts, check_invoice_status, get_recent_tickets, rotate_api_key]

Save as tools.py and run: uv run tools.py

Phase 4: Multi-agent LangGraph

Create graph.py with a router, specialist agents for each category, a compliance validator, and a supervisor interrupt. This is the engine that the Streamlit dashboard will drive.

        "You are a support triage router for Nimbus Cloud Solutions.\n"
        f"Classify the query into exactly one of: {', '.join(CATEGORIES)}.\n"
        "Return only the category name, nothing else.\n\n"
        f"User query: {query}"
    )
    response = llm.invoke(prompt)
    category = response.content.strip().lower()
    if category not in CATEGORIES:
        category = "escalation"
    return {"category": category, "next": category}

def make_specialist_node(category: str):
    def specialist_node(state: AgentState):
        prompt = SPECIALIST_PROMPTS[category]
        messages = [("system", prompt)] + state["messages"]
        response = llm_tools.invoke(messages)
        return {"messages": [response]}
    return specialist_node

def compliance_node(state: AgentState):
    text = state["messages"][-1].content.lower()
    sensitive = ["password", "secret", "credential", "api key"]
    if any(topic in text for topic in sensitive) and state.get("category") != "security":
        return {
            "messages": [AIMessage(content="Compliance check failed: sensitive topic handled outside security. Escalating.")],
            "next": "escalation",
        }
    return {"messages": [AIMessage(content="Compliance check passed.")], "next": "supervisor"}

def supervisor_node(state: AgentState):
    last = state["messages"][-1]
    payload = {
        "stage": state.get("category", "unknown"),
        "output": last.content,
    }
    action = interrupt({"question": f"Approve {payload['stage']} response?", "payload": payload})
    if action.get("approved"):
        return {"messages": [AIMessage(content=f"Supervisor approved {payload['stage']} response.")], "approved": True}
    return {"messages": [AIMessage(content="Supervisor rejected response. Escalating.")], "next": "escalation", "approved": False}

def escalate_node(state: AgentState):
    return {"messages": [AIMessage(content="This has been escalated to a human agent. Reference: NIMBUS-HUMAN-001.")]}

builder = StateGraph(AgentState)
builder.add_node("router", router_node)
for cat in CATEGORIES:
    builder.add_node(cat, make_specialist_node(cat))
builder.add_node("compliance", compliance_node)
builder.add_node("supervisor", supervisor_node)
builder.add_node("escalation", escalate_node)

builder.set_entry_point("router")
for cat in CATEGORIES:
    builder.add_conditional_edges("router", lambda s, c=cat: c, [cat])

for cat in CATEGORIES:
    builder.add_edge(cat, "compliance")

builder.add_conditional_edges(
    "compliance",
    lambda s: "escalation" if s.get("next") == "escalation" else "supervisor",
    {"escalation": "escalation", "supervisor": "supervisor"},
)
builder.add_conditional_edges(
    "supervisor",
    lambda s: "escalation" if s.get("next") == "escalation" else END,
    {"escalation": "escalation", END: END},
)
builder.add_edge("escalation", END)

graph = builder.compile()

if __name__ == "__main__":
    result = graph.invoke({"messages": [HumanMessage(content="Why was I charged twice this month?")]})
    for msg in result["messages"]:
        print(f"[{msg.type}]: {msg.content[:200]}")

Phase 6: Full Streamlit command center

Create app.py . It imports the reusable tools, single agent, and compiled graph from the previous phases, adds tabs for chat, trace, single-agent demo, and MCP tools, and handles the supervisor interrupt with a Streamlit approval button. 

import streamlit as st
from langchain_core.messages import HumanMessage
from langgraph.types import Command

from tools import NIMBUS_TOOLS, get_account_balance, list_accounts, check_invoice_status
from single_agent import llm_tools, name_to_tool
from graph import graph, CATEGORIES

st.set_page_config(page_title="Nimbus Support Command Center", layout="wide")
st.title("Nimbus Support Command Center")
st.caption("Multi-agent support with routing, tools, supervisor approval, and MCP.")

if "thread_id" not in st.session_state:
    st.session_state.thread_id = "streamlit-1"
if "pending_interrupt" not in st.session_state:
    st.session_state.pending_interrupt = None
if "trace" not in st.session_state:
    st.session_state.trace = []

tab_chat, tab_single, tab_trace, tab_mcp = st.tabs(
    ["Multi-Agent Chat", "Single Agent", "Agent Trace", "MCP / Tools"]
)

with tab_chat:
    query = st.text_input(
        "Ask Nimbus support:",
        "Why was I charged twice this month?",
        key="chat_query",
    )
    col_run, col_approve = st.columns([1, 1])
    with col_run:
        run_pressed = st.button("Run agents", key="run_agents")
    with col_approve:
        approve_pressed = st.button("Approve supervisor", key="approve_supervisor")

    config = {"configurable": {"thread_id": st.session_state.thread_id}}

    if run_pressed:
        with st.spinner("Routing and acting..."):
            result = graph.invoke(
                {"messages": [HumanMessage(content=query)]},
                config=config,
            )
            if hasattr(result, "__next__"):
                try:
                    result = next(result)
                except StopIteration:
                    result = {}
            st.session_state.trace = result.get("messages", [])
            st.session_state.pending_interrupt = result.get("__interrupt__")

    if st.session_state.pending_interrupt:
        st.warning("Supervisor approval required before continuing.")
        if approve_pressed:
            with st.spinner("Resuming with supervisor approval..."):
                resumed = graph.invoke(
                    Command(resume={"approved": True}),
                    config=config,
                )
                st.session_state.trace = resumed.get("messages", st.session_state.trace)
                st.session_state.pending_interrupt = None
                st.success("Supervisor approved.")

    for msg in st.session_state.trace:
        role = "user" if msg.type == "human" else "assistant"
        with st.chat_message(role):
            st.write(msg.content)

    if st.session_state.trace:
        last = st.session_state.trace[-1]
        st.json({"last_role": last.type, "last_content_preview": last.content[:200]})

with tab_single:
    single_query = st.text_input(
        "Ask the single tool-calling agent:",
        "What is my checking balance?",
        key="single_query",
    )
    if st.button("Run single agent", key="run_single"):
        messages = [HumanMessage(content=single_query)]
        response = llm_tools.invoke(messages)
        messages.append(response)
        for call in response.tool_calls:
            tool = name_to_tool[call["name"]]
            result = tool.invoke(call["args"])
            messages.append(ToolMessage(content=str(result), tool_call_id=call["id"]))
        final = llm_tools.invoke(messages)
        st.success(final.content)
        with st.expander("Tool calls"):
            st.json(response.tool_calls)

with tab_trace:
    st.write("Inspect the full message history produced by the multi-agent graph.")
    for i, msg in enumerate(st.session_state.trace, 1):
        st.write(f"{i}. **{msg.type}**: {msg.content[:300]}")

with tab_mcp:
    st.subheader("Direct tool calls")
    account = st.selectbox("Account", list_accounts(), key="mcp_account")
    if st.button("Get balance", key="mcp_balance"):
        st.json(get_account_balance(account))
    invoice = st.text_input("Invoice ID", "INV-2024-001", key="mcp_invoice")
    if st.button("Check invoice", key="mcp_invoice_btn"):
        st.write(check_invoice_status(invoice))

st.markdown("""
**What to try:**
- Billing: "Why was I charged twice this month?"
- Technical: "My API requests return 429."
- Security: "My API key was leaked."
- Escalation: "I want to speak to a human."
""")
