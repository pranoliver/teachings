# React: Modern Frontend Development

A single-page interactive tutorial covering React from fundamentals to a complete task-board capstone project.

## What's Included

- **Single HTML file**: `index.html` — open directly in any modern browser.
- **Sleek responsive layout**: left sidebar navigation, right content area.
- **Light & Dark themes**: Light default; toggle via the top-right button.
- **Google Font**: Outfit.
- **Tailwind CSS**: styling with a custom design, no build step required.
- **Syntax highlighting**: Highlight.js for JavaScript, JSX, CSS, and bash snippets.
- **Copy-to-clipboard buttons** on all code blocks.
- **Interactive quizzes** with instant feedback.
- **Next / Previous navigation** at the bottom of each section.
- **Capstone project**: A Kanban-style task board with add, move, and delete.

## Topics Covered

1. Introduction
2. What is React?
3. Setting Up a Project (Vite)
4. JSX
5. Components
6. Props
7. State with useState
8. Handling Events
9. Side Effects with useEffect
10. Rendering Lists
11. Forms & Controlled Inputs
12. Conditional Rendering
13. Lifting State Up
14. React Router
15. Context API
16. Capstone: Task Board
17. Best Practices

## How to Use

1. Open `react/index.html` in any modern web browser.
2. Use the left sidebar to jump between topics.
3. Toggle light/dark mode using the moon/sun icon in the header.
4. Work through checkpoints and quizzes to test your understanding.
5. Copy code blocks and paste them into a Vite React project to run them.

## No Server Required

All resources (Tailwind, fonts, icons, syntax highlighter) are loaded via CDN. You can open the file directly from your file system.

## Prerequisites

Students should be comfortable with HTML, CSS, and JavaScript before starting this tutorial. The [JavaScript Basics](../javascript-basics/) tutorial is a good prerequisite.

## Customization

If you'd like to add more topics or change colors:
- Edit the `<style>` block in `index.html` for custom CSS overrides.
- Add new `<section>` elements following the existing pattern.

Happy teaching and learning!
