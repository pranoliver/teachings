# TypeScript

A self-contained, interactive tutorial for learning TypeScript with real-world examples.

## What you'll learn

- Why TypeScript catches bugs before runtime
- Installing TypeScript and configuring `tsconfig.json`
- Basic types, functions, interfaces, and classes
- Arrays, tuples, enums, and literal unions
- Generics and type constraints
- Unions, intersections, and discriminated unions
- Built-in utility types
- Modules and project configuration
- TypeScript with React components
- TypeScript with Node.js and Express

## Structure

- `index.html` — Complete tutorial in a single file with sidebar navigation, dark mode, copyable code blocks, diagrams, and quizzes.
- `README.md` — This file.

## How to use

Open `index.html` directly in any modern web browser. No local server, build step, or internet is required after the page loads.

## Capstone

The final project is a typed **E-Commerce Cart** that demonstrates:

- Strongly typed `Product` and `CartItem` interfaces
- A `ShoppingCart` class with add, remove, update, and summary methods
- A generic `MemoryRepository<T>` storage layer
- Real-world totals with tax and discount calculations

## Recommended tools

- Node.js 18+ and npm
- VS Code for the best TypeScript experience
- `ts-node` or `tsx` for running TypeScript during development
