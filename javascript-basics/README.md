# JavaScript Basics

A beginner-friendly, single-page interactive tutorial covering the fundamentals of JavaScript programming.

## What's Included

- **Single HTML file**: `index.html` — open directly in any modern browser.
- **Sleek responsive layout**: left sidebar navigation, right content area.
- **Light & Dark themes**: Light is the default; toggle via the top-right button.
- **Google Font**: Outfit.
- **Tailwind CSS**: styling with a custom design, no build step required.
- **Syntax highlighting**: Highlight.js for code snippets.
- **Copy-to-clipboard buttons** on all code blocks.
- **Interactive in-browser code playgrounds** where you can run JavaScript directly.
- **Interactive elements**:
  - Checkpoints with self-check questions
  - Quizzes with instant feedback
  - "Try it yourself" exercises
- **Next / Previous navigation** at the bottom of each section.
- **Capstone project**: A small interactive to-do list app built chapter by chapter.

## Topics Covered

1. Introduction
2. What is JavaScript?
3. Where to Write JavaScript
4. Variables: let, const, var
5. Data Types
6. Operators
7. Strings and Template Literals
8. Conditionals
9. Loops
10. Functions
11. Arrays
12. Objects
13. The DOM
14. Selecting and Modifying Elements
15. Events
16. Building a Small Interactive App
17. Debugging Tips
18. Best Practices

## Capstone Project

By the end of the tutorial, students will have built a simple interactive to-do list with:
- Add tasks
- Mark tasks complete
- Delete tasks
- Local data storage in memory

## How to Use

1. Open `javascript-basics/index.html` in any modern web browser.
2. Use the left sidebar to jump between topics.
3. Toggle light/dark mode using the moon/sun icon in the header.
4. Work through checkpoints and quizzes to test your understanding.
5. Copy code blocks or run them directly in the embedded playground.

## No Server Required

All resources (Tailwind, fonts, icons, syntax highlighter) are loaded via CDN. You can open the file directly from your file system.

## Customization

If you'd like to add more topics or change colors:
- Edit the `<style>` block in `index.html` for custom CSS overrides.
- Add new `<section>` elements following the existing pattern.
