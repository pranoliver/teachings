Chapter 3

Where to Write JavaScript

You can write JavaScript directly inside an HTML file, or in a separate .js file. The browser runs it when the page loads.

Internal script 

<script>
  console.log("Hello, JS!");
</script>

External script 

<script src="app.js"></script>

Place this just before the closing </body> tag.

Browser console

Every browser has a console where you can type and run JavaScript. Open it with:

  • F12 or Cmd + Option + J (Mac)
  • Right-click → Inspect → Console tab
  • Type console.log("hi") and press Enter

Chapter 4

Variables: let, const, var

Variables are labeled containers for storing data. Modern JavaScript uses let and const . 

// let: value can change
let score = 0;
score = 10;
// const: value cannot be reassigned
const name = "Alex";
// name = "Sam"; // ❌ Error!
// var is old-fashioned; avoid it
var oldWay = "not recommended";
console.log(score, name);

When to use what

  • Use const by default.
  • Use let when the value will change.
  • Avoid var ; it has confusing behavior.

Try it in the playground 

let counter = 5;
counter = counter + 3;
console.log(counter);

Chapter 5

Data Types

JavaScript has several built-in data types. The typeof operator tells you what kind of value something is. 

const message = "Hello"; // string
const age = 25; // number
const isActive = true; // boolean
const user = { name: "Alex" }; // object
const items = [1, 2, 3]; // array (also an object)
const nothing = null; // null
let notDefined; // undefined
console.log(typeof message); // "string"
console.log(typeof age); // "number"
console.log(typeof isActive); // "boolean"
console.log(typeof user); // "object"
console.log(typeof items); // "object"

Strings and numbers in detail

Strings are text wrapped in quotes. Numbers can be integers or decimals. JavaScript does not separate int and float — everything is just number .

Chapter 6

Operators

Operators perform actions on values: math, comparison, assignment, and more. 

// Math
const sum = 5 + 3; // 8
const product = 5 * 3; // 15
const remainder = 10 % 3; // 1
// Assignment shorthand
let count = 0;
count++; // 1
count += 5; // 6
// Comparison
console.log(5 === 5); // true
console.log(5 == "5"); // true (loose, avoid)
console.log(5 === "5"); // false (strict, prefer)
// Logical
const isAdult = age >= 18 && hasID === true;
const isWeekend = day === "Sat" || day === "Sun";
const isNotReady = !isReady;

Prefer strict equality

Always use === and !== instead of == and != . Strict comparison checks both value and type, preventing unexpected conversions.

Chapter 7

Strings & Template Literals

Strings store text. Template literals (backticks) make it easy to include variables inside strings. 

const firstName = "Alex";
const lastName = "Lee";
// Old way: concatenation
const full = firstName + " " + lastName;
// Modern way: template literal
const greeting = `Hello, ${full}!`;
console.log(greeting); // Hello, Alex Lee!
// Multiline strings
const poem = `Roses are red,
Violets are blue,
JavaScript is fun,
And so are you.`;
console.log(poem);

Chapter 8

Conditionals

Conditionals let your code make decisions based on true or false checks. 

const score = 85;
if (score >= 90) {
  console.log("A grade");
} else if (score >= 80) {
  console.log("B grade");
} else if (score >= 70) {
  console.log("C grade");
} else {
  console.log("Keep practicing");
}
// Ternary operator for simple cases
const message = score >= 50 ? "Pass" : "Fail";
console.log(message);

Truthy and falsy values

Some values act like false in conditions:

  • false , 0 , "" , null , undefined , NaN
  • Everything else is truthy, including "0" and []

Try it in the playground 

const temperature = 28;
if (temperature > 30) {
  console.log("It's hot!");
} else if (temperature > 20) {
  console.log("It's warm.");
} else {
  console.log("It's cold.");

Chapter 9

Loops

Loops repeat code. Use them when you want to do the same thing many times. 

// for loop
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// while loop
let n = 1;
while (n <= 3) {
  console.log("while", n);
  n++;
}
// for...of for arrays
const fruits = ["apple", "banana", "cherry"];
for (const fruit of fruits) {
  console.log(fruit);
}

Loop anatomy

A for loop has three parts: initialization ( let i = 1 ), condition ( i <= 5 ), and update ( i++ ). The loop runs while the condition is true.

Chapter 10

Functions

Functions are reusable blocks of code. They can accept inputs and return outputs. 

// Function declaration
function greet(name) {
  return `Hello, ${name}!`;
}
// Function expression
const add = function (a, b) {
  return a + b;
};
// Arrow function
const multiply = (a, b) => a * b;
console.log(greet("Alex"));
console.log(add(2, 3));
console.log(multiply(4, 5));

Arrow functions

Arrow functions are a shorter syntax. If the body is a single expression, you can skip the return keyword and curly braces.

Chapter 11

Arrays

Arrays store ordered lists of values. They are one of the most useful tools in JavaScript. 

const colors = ["red", "green", "blue"];
console.log(colors[0]); // "red"
console.log(colors.length); // 3
colors.push("yellow"); // add to end
colors.pop(); // remove from end
colors.unshift("purple"); // add to start
// Common array methods
const numbers = [1, 2, 3, 4];
const doubled = numbers.map((n) => n * 2);
const evens = numbers.filter((n) => n % 2 === 0);
const total = numbers.reduce((sum, n) => sum + n, 0);
console.log(doubled); // [2, 4, 6, 8]
console.log(evens); // [2, 4]
console.log(total); // 10

Try it in the playground 

const names = ["Alex", "Sam", "Jordan"];
names.push("Taylor");
console.log(names);
console.log("Total names:", names.length);

Chapter 12

Objects

Objects group related data using key-value pairs. They are perfect for representing real-world things. 

const user = {
  name: "Alex",
  age: 25,
  isAdmin: false,
  greet() {
    return `Hi, I'm ${this.name}`;
  },
};
console.log(user.name); // "Alex"
console.log(user["age"]); // 25
console.log(user.greet()); // "Hi, I'm Alex"
// Update and add properties
user.age = 26;
user.country = "Canada";
console.log(user);

Destructuring 

const { name, age } = user;
console.log(name, age);

Destructuring pulls values out of an object into separate variables in a clean way.

Chapter 14

Selecting & Modifying Elements

JavaScript provides methods to grab HTML elements and change their content, style, or attributes. 

// Select one element
const heading = document.querySelector("h1");
// Select many elements
const items = document.querySelectorAll(".item");
// Change text
heading.textContent = "New title";
// Change style
heading.style.color = "blue";
// Add or remove classes
heading.classList.add("highlight");
heading.classList.remove("dark");
heading.classList.toggle("visible");
// Read or set attributes
const link = document.querySelector("a");
console.log(link.getAttribute("href"));
link.setAttribute("href", "https://example.com");

Chapter 16

Build a Small App: To-Do List

This capstone project combines variables, arrays, functions, DOM selection, and events into one useful mini-app.

Live to-do list 

const input = document.querySelector("#todo-input");
const addBtn = document.querySelector("#todo-add");
const list = document.querySelector("#todo-list");
function addTask() {
  const text = input.value.trim();
  if (!text) return;
  const li = document.createElement("li");
  li.className =
    "flex items-center justify-between px-3 py-2 rounded-lg bg-[var(--panel)] border border-[var(--border)]";
  li.innerHTML = `
    ${text}
      Done
      Delete
  `;
  li.querySelector(".done-btn").addEventListener("click", () => {
    li.querySelector(".todo-text").classList.toggle("line-through");
    li.querySelector(".todo-text").classList.toggle("text-[var(--muted)]");
  });
  li.querySelector(".delete-btn").addEventListener("click", () => {
    li.remove();
  });
  list.appendChild(li);
  input.value = "";
  input.focus();
}
addBtn.addEventListener("click", addTask);
input.addEventListener("keydown", (e) => {
  if (e.key === "Enter") addTask();
});

Chapter 17

Debugging Tips

Bugs are a normal part of coding. These habits help you find and fix problems faster.

Helpful techniques

  • Read error messages carefully; they usually include a line number.
  • Use console.log() to inspect values at different points.
  • Check for typos in variable and function names.
  • Make sure quotes and brackets are matched.
  • Use the browser debugger with breakpoints.
  • Comment out code to isolate the problem. 
// Add logs to see what's happening
function add(a, b) {
  console.log("a:", a, "b:", b);
  return a + b;
}
add(2, 3);

Chapter 18

Best Practices

Good habits make your code easier to read, debug, and maintain.

Code style

  • Use clear, descriptive variable names.
  • Prefer const , then let , never var .
  • Use strict equality === .
  • Keep functions small and focused.

Working habits

  • Test small pieces of code as you write them.
  • Use the console to explore values.
  • Break big problems into smaller functions.
  • Read error messages before searching online.
