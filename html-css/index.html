Introduction

Welcome! This guide teaches you how to build web pages with HTML and CSS. By the end, you'll understand the structure of every website and be able to create your own responsive, good-looking pages.

Before you start

  • A text editor (VS Code, Sublime Text, or even Notepad)
  • A modern web browser
  • No coding experience required

What you'll learn

  • ✓ How web pages are structured
  • ✓ HTML5 semantic elements
  • ✓ Styling with CSS3
  • ✓ Layouts with Flexbox and Grid
  • ✓ Responsive design and media queries
  • ✓ A complete portfolio page project

What are HTML and CSS?

  • HTML (HyperText Markup Language) defines the structure and meaning of content.
  • CSS (Cascading Style Sheets) controls the visual presentation: colors, fonts, spacing, layout.

Analogy: HTML is the skeleton of a website; CSS is the skin, clothes, and makeup.

More practice ideas

  • Build a personal portfolio page with your bio, photo, and contact links.
  • Create a product landing page with a hero section, features list, and footer.
  • Style a simple recipe card with an image, ingredients list, and instructions.

Chapter 2

How the Web Works

When you visit a website, your browser asks a server for files. The server sends back HTML, CSS, images, and sometimes JavaScript.

Request → Response cycle

Browser asks → Server answers → Browser builds the page

Key terms

URL
The address of a web page.
HTTP/HTTPS
Protocols that transfer web data.
Server
A computer that stores and serves files.
Browser
Software that reads HTML/CSS and displays the page.

Chapter 3

Your First HTML Page

An HTML file is just a text file with the .html extension. You can create one with any text editor. 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first web page.</p>
  </body>
</html>

How to view it

  1. Save the code above as index.html on your computer.
  2. Double-click the file, or right-click and choose "Open with browser".
  3. You should see a heading and a paragraph.

Checkpoint

Chapter 4

HTML Document Structure

Every HTML page follows a standard structure. Think of it like the blueprint of a house.

Document anatomy

The body holds everything the user sees; the head holds configuration. 

<!doctype html>
<!-- declares HTML5 -->
<html lang="en">
  <!-- root element -->
  <head>
    <!-- metadata, not visible -->
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Page Title</title>
  </head>
  <body>
    <!-- visible content -->
    <!-- everything the user sees goes here -->
  </body>
</html>

Chapter 5

Text Elements & Headings

HTML provides many elements to structure text. Headings create hierarchy; paragraphs and lists organize content. 

<h1>Main title</h1>
<h2>Section heading</h2>
<h3>Subheading</h3>
<p>This is a paragraph. Paragraphs are blocks of text.</p>
<p>You can make text <strong>bold</strong> or <em>italic</em>.</p>
<p>
  Line breaks are created with <br />
  like this.
</p>

Heading levels

There are six heading levels, from <h1> (most important) to <h6> (least important). Use them in order — don't skip levels just to make text bigger.

Chapter 6

Links, Images & Lists

The web is built on links. Images and lists help organize and enrich your content. 

<!-- Link to another page -->
<a href="https://github.com">Visit GitHub</a>
<!-- Open link in new tab -->
<a href="https://github.com" target="_blank" rel="noopener">Visit GitHub</a>
<!-- Image -->
<img src="photo.jpg" alt="A scenic mountain view" width="400" />
<!-- Unordered list -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
<!-- Ordered list -->
<ol>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Build projects</li>
</ol>

Important: always write alt text

The alt attribute describes an image. It is shown if the image fails to load and is read by screen readers for visually impaired users.

Chapter 7

Semantic HTML5 Elements

Semantic elements describe their meaning to the browser and to developers. They improve accessibility and SEO. 

<header>
  <nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
  </nav>
</header>
<main>
  <article>
    <h1>Blog Post Title</h1>
    <p>Article content goes here...</p>
  </article>
  <aside>
    <p>Related links or author info.</p>
  </aside>
</main>
<footer>
  <p>&copy; 2026 My Name</p>
</footer>

Common semantic elements

<header>
Introductory content or navigation.
<nav>
Navigation links.
<main>
The dominant content of the page.
<article>
Self-contained piece of content.
<section>
Thematic grouping of content.
<footer>
Footer for a page or section.

Chapter 8

Forms & Input Types

Forms collect information from users: signups, searches, contact messages, and more. 

<form action="/submit" method="POST">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name" required />
  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required />
  <label for="message">Message:</label>
  <textarea id="message" name="message" rows="4"></textarea>
  <button type="submit">Send</button>
</form>

Common input types

  • text — single-line text
  • email — validates email format
  • password — hides typed characters
  • number — numeric input
  • date — date picker
  • checkbox / radio — choices
  • file — upload files

Chapter 9

Accessibility Basics

Accessibility means making websites usable by everyone, including people with disabilities. It also improves SEO and usability for all users.

Key practices

  • Use proper heading hierarchy ( h1 → h2 → h3 ).
  • Always include meaningful alt text on images.
  • Associate every form input with a <label> .
  • Ensure sufficient color contrast.
  • Make interactive elements keyboard-focusable.
  • Use semantic elements instead of generic <div> s where possible. 
<!-- Good: label linked to input -->
<label for="username">Username</label>
<input type="text" id="username" name="username" />
<!-- Bad: no association -->
<p>Username</p>
<input type="text" name="username" />
<!-- Good: descriptive alt text -->
<img src="cat.jpg" alt="A sleeping orange cat" />

Checkpoint

Go back through your page so far and make sure every image has alt text and every input has a linked label.

Chapter 10

Introduction to CSS

CSS describes how HTML elements should look. You can write CSS in three ways: inline, internally, or externally.

Inline 

<p style="color: red;">Red text</p>

Style directly on the element. Not recommended for most cases.

Internal 

<head>
  <style>
    p {
      color: red;
    }
  </style>
</head>

Style inside a <style> tag. Good for small demos.

External 

<link rel="stylesheet" href="styles.css">

Best for real projects. Separates content from design.

CSS syntax 

selector {
  property: value;
}
/* Example */
h1 {
  color: blue;
  font-size: 2rem;
}

A selector targets HTML elements. A declaration is a property-value pair.

Chapter 11

Colors, Fonts & Units

Colors can be named, hex, RGB, or HSL. Fonts can be system defaults or loaded from services like Google Fonts. CSS units define sizes. 

/* Different ways to write colors */
color: red;
color: #ff0000;
color: rgb(255, 0, 0);
color: hsl(0, 100%, 50%);
color: rgba(255, 0, 0, 0.5); /* with transparency */
/* Font family */
font-family: "Outfit", sans-serif;
font-size: 1.25rem;
font-weight: 700;
line-height: 1.6;
/* Common units */
width: 100%; /* percentage of parent */
margin: 16px; /* pixels */
padding: 1rem; /* relative to root font size */
font-size: 1.2em; /* relative to parent font size */
border-radius: 8px; /* fixed size */

Adding a Google Font 

<!-- In the head of your HTML -->
<link
  href="https://fonts.googleapis.com/css2?family=Outfit:wght@400;700&display=swap"
  rel="stylesheet"
/>

Then use it in CSS: font-family: 'Outfit', sans-serif;

Chapter 12

The Box Model

Every HTML element is a rectangular box made of four layers: content, padding, border, and margin. Understanding this is essential for layout.

Layers of the box

From outside in: margin, border, padding, then content. 

.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 2px solid black;
  margin: 30px;
  background-color: lightblue;
}

Box-sizing

By default, width only sets the content size. Use box-sizing: border-box to make width include padding and border. 

* {
  box-sizing: border-box;
}

Chapter 13

Display, Position & Z-Index

These properties control how elements appear in the document flow and how they overlap each other.

Display values

  • block — takes full width, starts on new line.
  • inline — flows with text, no width/height.
  • inline-block — inline but accepts sizing.
  • none — removes the element from layout.

Position values

  • static — default position.
  • relative — offset from normal position.
  • absolute — positioned relative to nearest positioned ancestor.
  • fixed — positioned relative to viewport.
  • sticky — switches between relative and fixed. 
/* Make a sticky header */
header {
  position: sticky;
  top: 0;
  z-index: 10;
  background: white;
}
/* Overlap an element */
.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}

Chapter 14

CSS Variables (Custom Properties)

CSS variables let you store values like colors and spacing so you can reuse them across your stylesheet. They make themes and updates much easier. 

/* Define variables on the root element */
:root {
  --brand: #2f81f7;
  --text: #1f2328;
  --bg: #f6f8fa;
  --radius: 8px;
  --space: 1rem;
}
/* Use them anywhere */
body {
  color: var(--text);
  background-color: var(--bg);
}
button {
  background: var(--brand);
  border-radius: var(--radius);
  padding: var(--space);
}

Why use variables?

  • Update a color once, see it everywhere.
  • Build light/dark themes by changing a few values.
  • Keep spacing and sizing consistent.

Chapter 15

Flexbox

Flexbox is a one-dimensional layout system. It's perfect for aligning items in a row or column. 

.container {
  display: flex;
  justify-content: center; /* horizontal alignment */
  align-items: center; /* vertical alignment */
  gap: 1rem; /* space between items */
  flex-wrap: wrap; /* allow items to wrap */
}
.item {
  flex: 1; /* grow to fill space */
  min-width: 200px;
}

Chapter 16

CSS Grid

Grid is a two-dimensional layout system. It handles both rows and columns, making it ideal for page-level layouts. 

.page {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
  gap: 1rem;
}
header {
  grid-column: 1 / -1;
}
main {
  grid-column: 2;
}
aside {
  grid-column: 1;
  grid-row: 2;
}
footer {
  grid-column: 1 / -1;
}

Chapter 17

Responsive Design & Media Queries

Responsive design means your page looks good on phones, tablets, and desktops. Media queries let you apply CSS only at certain screen sizes. 

/* Mobile-first approach: default styles first, then larger screens */
.container {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}
/* Tablets */
@media (min-width: 640px) {
  .container {
    grid-template-columns: repeat(2, 1fr);
  }
}
/* Desktops */
@media (min-width: 1024px) {
  .container {
    grid-template-columns: repeat(3, 1fr);
  }
}

Mobile-first thinking

Start with the smallest screen layout, then use min-width media queries to enhance the design for larger screens. This is the most common modern approach.

Checkpoint

Resize your browser window while viewing your page. Does the layout adapt? If not, add a media query.

Chapter 18

Transitions & Animations

CSS can make changes smooth and create moving effects. Use transitions for simple hover effects and animations for more complex sequences.

Transitions

Hover over the box below to see a smooth change.

Hover me

Keyframe animations

These boxes run forever without any user input. 

/* Smooth hover transition */
.anim-demo {
  transition:
    transform 0.3s ease,
    box-shadow 0.3s ease;
}
.anim-demo:hover {
  transform: scale(1.05);
  box-shadow: 0 20px 40px rgba(0, 0, 0, 0.2);
}
/* Continuous bounce */
@keyframes bounce {
  0%,
  100% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-40px);
  }
}
.ball {
  animation: bounce 1.2s ease-in-out infinite;
}

Chapter 19

CSS Frameworks Introduction

CSS frameworks provide pre-built components and utility classes so you can build faster. They are useful, but understanding plain HTML and CSS first is important.

Tailwind CSS

Utility-first framework. Compose designs by combining small classes directly in HTML.

Bootstrap

Component-based framework with ready-made buttons, cards, navbars, and grids.

Bulma

Modern CSS-only framework with clean class names and flexible columns. 

<!-- Example: a Tailwind-style button -->
<button class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600">
  Click me
</button>

When to use a framework

  • You need to prototype quickly.
  • You want consistent design without writing every rule.
  • You are working on a team with shared conventions.

Chapter 21

Best Practices & Resources

You're now equipped to build real web pages. These habits will keep your code clean, accessible, and maintainable.

HTML habits

  • Use semantic elements.
  • Validate your HTML with the W3C validator.
  • Write meaningful alt text.
  • Keep accessibility in mind from the start.

CSS habits

  • Use CSS variables for colors and spacing.
  • Prefer mobile-first media queries.
  • Avoid overly specific selectors.
  • Comment complex layout rules.
