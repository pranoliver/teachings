General

CLI

Command Line Interface. A text-based way to interact with a computer by typing commands instead of using a graphical interface.

IDE / Code Editor

Integrated Development Environment or a simpler code editor used to write and manage code. Examples: VS Code, JetBrains, Vim.

Syntax

The rules that define the structure of a programming language. Syntax errors happen when code is written incorrectly.

Runtime

The environment in which a program executes. Node.js is the runtime for JavaScript on the server.

Library / Framework

A library is reusable code you call. A framework is a larger structure that calls your code and defines how an application is organized.

Programming

Variable

A named container for storing data that can be referenced and changed during program execution.

Function

A reusable block of code that performs a specific task and may accept inputs and return outputs.

Data Type

A classification of data such as string, number, boolean, object, or array. TypeScript adds static type checking.

Asynchronous Programming

A way to run operations without blocking the main thread. Common patterns include callbacks, promises, and async/await.

Generic

A type or function that works with multiple data types while preserving type safety, such as Array in TypeScript.

Web

API

Application Programming Interface. A contract that lets different software systems communicate, often over HTTP.

REST API

A style of API design that uses HTTP methods like GET, POST, PUT, and DELETE to interact with resources.

Middleware

Functions that run between a request and a response in a web server, often used for logging, authentication, or parsing.

JWT

JSON Web Token. A compact, self-contained way to securely transmit user identity and claims between parties.

Component

A reusable, self-contained piece of a user interface. React applications are built from components.

Hook

A React function that lets components use state and other React features. Examples: useState and useEffect.

Databases

SQL

Structured Query Language. A standard language for storing, manipulating, and querying data in relational databases.

JOIN

An SQL operation that combines rows from two or more tables based on a related column.

Index

A database structure that speeds up queries by making lookups faster, similar to a book index.

Transaction

A sequence of database operations that must succeed or fail as a single unit, following ACID properties.

DevOps

CI/CD

Continuous Integration and Continuous Delivery/Deployment. The practice of automatically building, testing, and releasing software.

Container

A lightweight, standalone package of software that includes everything needed to run an application. Docker is the most common container tool.

Docker Image

A read-only template used to create containers. It includes code, runtime, libraries, and configuration.

Container Registry

A service that stores and distributes Docker images. Examples: Docker Hub, GitHub Container Registry, AWS ECR.

Infrastructure as Code (IaC)

Managing infrastructure through configuration files rather than manual setup. Examples: Terraform, Ansible, CloudFormation, Docker Compose.

Environment

A distinct deployment target such as development, staging, or production, each with its own configuration and secrets.
