Loops

Loops repeat code. Python has for loops for iterating and while loops for conditions.

# for loop
for i in range(5):
    print(i)

# Loop over a list
fruits = ["apple", "banana", "cherry"]

    print(n)

    if num % 2 == 0:
        continue
    print(num)

Loop keywords

  • break — exits the loop immediately
  • continue — skips to the next iteration
  • else on a loop — runs if the loop wasn't broken

Chapter 11

Dictionaries & Sets

Dictionaries store key-value pairs. Sets store unique, unordered values.

# Dictionary
user = {
    "name": "Alex",
    "age": 25,
    "city": "Paris"
}

user["age"] = 26

numbers.add(4)
numbers.remove(2)
print(numbers)

# Set operations
a = {1, 2, 3}

print(a & b)  # intersection: {2, 3}

When to use what

  • List — ordered items that may change
  • Tuple — ordered items that should not change
  • Dictionary — labeled data, fast lookups
  • Set — unique values, membership tests

Chapter 14

Error Handling

Errors are a normal part of programming. Use try/except blocks to handle them gracefully.

try:
    number = int(input("Enter a number: "))
    result = 10 / number
    print(result)
except ValueError:
    print("That's not a valid number.")
except ZeroDivisionError:
    print("You can't divide by zero.")
except Exception as e:
    print(f"Something went wrong: {e}")
else:
    print("Calculation succeeded.")
finally:
    print("This always runs.")

Best practice

Catch specific exceptions when possible. Avoid bare except: because it can hide bugs.

Chapter 17

Lambda Functions

Lambda functions are small, anonymous functions defined with the lambda keyword.

# A simple lambda
add = lambda a, b: a + b
print(add(2, 3))  # 5

# Lambdas are often used with sorted
people = [
    {"name": "Alice", "age": 30},
    {"name": "Bob", "age": 25},
]

print(sorted_people)

# Map with lambda
numbers = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, numbers))
print(doubled)

When to use lambdas

Use lambdas for short, throwaway functions. If the logic is complex, use a regular def with a name.

Chapter 18

Map, Filter, and Reduce

These functional tools process collections without explicit loops.

from functools import reduce

numbers = [1, 2, 3, 4, 5]

# map: transform each item
doubled = list(map(lambda x: x * 2, numbers))
print(doubled)  # [2, 4, 6, 8, 10]

# filter: keep items that match a condition
evens = list(filter(lambda x: x % 2 == 0, numbers))
print(evens)  # [2, 4]

# reduce: combine all items into one value
product = reduce(lambda a, b: a * b, numbers)
print(product)  # 120

Chapter 20

Inheritance & Polymorphism

Inheritance lets a new class reuse and extend an existing class. Polymorphism means different classes can respond to the same method call in their own way.

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("Subclasses must implement this")

class Cat(Animal):
    def speak(self):
        return f"{self.name} says meow"

class Dog(Animal):
    def speak(self):
        return f"{self.name} says woof"

animals = [Cat("Whiskers"), Dog("Buddy")]
for animal in animals:
    print(animal.speak())

Chapter 21

Iterators

An iterator is an object that produces values one at a time. Lists, tuples, dictionaries, and strings are all iterable.

# Using iter() and next()
fruits = ["apple", "banana", "cherry"]
iterator = iter(fruits)

print(next(iterator))  # apple
print(next(iterator))  # banana
print(next(iterator))  # cherry

# Making your own iterator class
class Countdown:
    def __init__(self, start):
        self.start = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.start <= 0:
            raise StopIteration
        self.start -= 1
        return self.start + 1

for num in Countdown(5):
    print(num)

Chapter 22

Generators

Generators are functions that produce a sequence of values lazily, pausing between each one. They save memory for large datasets.

# Generator function
def count_up_to(n):
    count = 1
    while count <= n:
        yield count
        count += 1

for num in count_up_to(5):
    print(num)

# Generator expression
squares = (x ** 2 for x in range(1000000))
print(next(squares))  # 0
print(next(squares))  # 1

Why generators matter

  • They don't store all values in memory at once.
  • They are perfect for reading large files or infinite sequences.
  • They pause execution with yield and resume on the next call.

Chapter 23

Decorators

Decorators are functions that wrap other functions to add behavior. They are a powerful advanced Python feature.

import functools
import time

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"{func.__name__} took {elapsed:.4f} seconds")
        return result
    return wrapper

@timer
def slow_function():
    time.sleep(0.5)
    return "Done"

slow_function()

How it works

@timer above a function is shorthand for slow_function = timer(slow_function). The wrapper adds timing without changing the original function.

Chapter 24

Context Managers

Context managers handle setup and cleanup automatically. You use them whenever you see with.

# Built-in context manager
with open("data.txt", "w") as f:
    f.write("safe file handling")
# File is automatically closed here

# Custom context manager
class Timer:
    def __enter__(self):
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        elapsed = time.time() - self.start
        print(f"Elapsed: {elapsed:.4f}s")
        return False

with Timer():
    time.sleep(0.3)

# Using contextlib
from contextlib import contextmanager

@contextmanager
def managed_resource():
    print("Setup")
    yield
    print("Cleanup")

with managed_resource():
    print("Working")

Chapter 26

Using uv as a Package Manager

Modern Python projects can use uv, a fast, all-in-one Python project manager written in Rust by Astral. It can manage Python versions, create virtual environments, install packages, lock dependencies, run scripts, and install command-line tools.

Classic tools vs. uv's unified workflow

This section is advanced. The classic pip + venv workflow you learned in the previous chapter still works everywhere.

Install uv

# Using pip (works on any Python installation)
pip install uv

# Or use Astral's official installers
# macOS / Linux:
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows PowerShell:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Core uv workflows

# Create a virtual environment (no manual activation needed)
uv venv

# Install packages
uv pip install requests

# Run a script inside the managed environment
uv run python script.py

# Add a dependency to pyproject.toml and install it
uv add rich

# Remove a dependency
uv remove rich

# Install exactly what pyproject.toml requires
uv sync

# Generate / update a lockfile for reproducible installs
uv lock

# Compile a requirements file from pyproject.toml
uv pip compile pyproject.toml -o requirements.txt

# Install and run an isolated CLI tool
uvx ruff check .
uv tool install ruff

Manage Python interpreters

# See available Python versions
uv python list

# Install a specific Python version
uv python install 3.12

# Pin a project to a Python version
uv python pin 3.12

Why use uv? Why keep pip/venv?

uv advantages

  • One tool replaces many: pip, venv, pip-tools, virtualenv, pipx.
  • Much faster package resolution and installation.
  • Built-in lockfile for reproducible environments.
  • Runs scripts and tools without manual activation.

When pip/venv still makes sense

  • Teams or servers where only standard tools are allowed.
  • Older projects already using requirements.txt and pip.
  • Teaching or documenting the canonical Python workflow.
  • You only need a tiny one-off package install.

Chapter 27

Capstone Project: Smart Expense Tracker

This capstone pulls together everything you have learned: data structures, functions, file handling, error handling, and modular design. You will build a real, useful terminal application that can persist expenses, categorize them, set budgets, and export reports.

What you will build

A command-line expense tracker. Users can add expenses, list them, filter by category or date, see totals and budgets, update or delete entries, and export a monthly report to a CSV file.

Requirements

  • Storage: Save expenses to a JSON file so data persists between runs.
  • Expense fields: Each expense has an ID, date, description, category, and amount.
  • Add: Add a new expense with a description, category, and amount. Auto-generate the ID and date if not provided.
  • List: Display all expenses in a readable table with optional category filter.
  • Update & delete: Edit an expense by ID or remove it entirely.
  • Budgets: Set a monthly budget per category. Warn when spending reaches 80% and error when it exceeds 100%.
  • Summary: Show total spending, totals by category, and remaining budget.
  • Export: Export expenses to a CSV file for spreadsheets.
  • Validation: Handle invalid amounts, missing files, and bad user input gracefully.

Design overview

expense_tracker/
├── main.py          # entry point and command loop
├── storage.py       # load / save JSON data
├── models.py        # Expense and Budget classes
├── operations.py    # add, list, update, delete, summarize
└── reports.py       # CSV export helpers

Full solution (modular files)

The project is split into five small, focused files. You can either keep them separate or combine them into one file. The structure matches the design overview above.

1. storage.py — save and load JSON

"""Storage helpers for the Smart Expense Tracker."""

import json
import os


def load_json(filename, default):
    """Load JSON from *filename* or return *default* if it does not exist."""
    if not os.path.exists(filename):
        return default
    try:
        with open(filename, "r", encoding="utf-8") as f:
            return json.load(f)
    except (json.JSONDecodeError, OSError):
        print(f"Warning: {filename} could not be read. Starting fresh.")
        return default


def save_json(filename, data):
    """Save *data* to *filename* as formatted JSON."""
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2)

2. models.py — data builders

"""Data models and helpers for the Smart Expense Tracker."""

from datetime import datetime


def next_id(items):
    """Return the next available integer ID for a list of dict items."""
    if not items:
        return 1
    return max(item["id"] for item in items) + 1


def make_expense(description, category, amount, date=None, expense_id=None, existing=None):
    """Create a validated expense dictionary."""
    if date is None:
        date = datetime.now().strftime("%Y-%m-%d")
    return {
        "id": expense_id if expense_id is not None else next_id(existing or []),
        "date": date,
        "description": description,
        "category": category,
        "amount": round(float(amount), 2),
    }

3. operations.py — business logic

"""Core business operations for the Smart Expense Tracker."""

from collections import defaultdict
from expense_tracker.storage import save_json
from expense_tracker.models import make_expense


DATA_FILE = "expenses.json"
BUDGET_FILE = "budgets.json"


def _to_positive_float(value):
    """Convert *value* to a positive float, raising ValueError otherwise."""
    amount = float(value)
    if amount <= 0:
        raise ValueError("Amount must be positive")
    return amount


def add_expense(expenses, budgets, description, category, amount):
    """Add a new expense and persist it, then show budget warnings if any."""
    try:
        amount = _to_positive_float(amount)
    except ValueError as e:
        print(f"Invalid amount: {e}")
        return

    expense = make_expense(description, category, amount, existing=expenses)
    expenses.append(expense)
    save_json(DATA_FILE, expenses)

    budget = budgets.get(category)
    if budget:
        spent = sum(e["amount"] for e in expenses if e["category"] == category)
        percent = spent / budget * 100
        if spent > budget:
            print(f"⚠️  Over budget for {category}! Spent ${spent:.2f} / ${budget:.2f}")
        elif percent >= 80:
            print(f"⚠️  You have used {percent:.1f}% of your {category} budget.")

    print(f"Added expense #{expense['id']}: {description} (${amount:.2f}) [{category}]")


def list_expenses(expenses, category=None):
    """Print expenses as a table, optionally filtered by category."""
    filtered = [e for e in expenses if category is None or e["category"] == category]
    if not filtered:
        print("No expenses found.")
        return

    print(f"\n{'ID':<5}{'Date':<12}{'Category':<15}{'Description':<25}{'Amount':<10}")
    print("-" * 70)
    for e in filtered:
        print(f"{e['id']:<5}{e['date']:<12}{e['category']:<15}{e['description']:<25}${e['amount']:<9.2f}")
    print("-" * 70)
    print(f"Total: ${sum(e['amount'] for e in filtered):.2f}\n")


def update_expense(expenses, expense_id, **changes):
    """Update one or more fields of the expense with the given ID."""
    for e in expenses:
        if e["id"] == expense_id:
            for key, value in changes.items():
                if value is None:
                    continue
                if key == "amount":
                    value = _to_positive_float(value)
                e[key] = value
            save_json(DATA_FILE, expenses)
            print(f"Updated expense #{expense_id}")
            return
    print(f"Expense #{expense_id} not found.")


def delete_expense(expenses, expense_id):
    """Remove the expense with the given ID if it exists."""
    original_len = len(expenses)
    expenses[:] = [e for e in expenses if e["id"] != expense_id]
    if len(expenses) < original_len:
        save_json(DATA_FILE, expenses)
        print(f"Deleted expense #{expense_id}")
    else:
        print(f"Expense #{expense_id} not found.")


def summarize(expenses, budgets):
    """Show total spending, category totals, and remaining budgets."""
    if not expenses:
        print("No expenses to summarize.")
        return

    print("\n--- Spending Summary ---")
    total = sum(e["amount"] for e in expenses)
    print(f"Total spending: ${total:.2f}")

    by_category = defaultdict(float)
    for e in expenses:
        by_category[e["category"]] += e["amount"]

    print("\nBy category:")
    for category, spent in sorted(by_category.items()):
        budget = budgets.get(category)
        line = f"  {category}: ${spent:.2f}"
        if budget is not None:
            remaining = budget - spent
            line += f" (budget ${budget:.2f}, remaining ${remaining:.2f})"
        print(line)
    print()


def set_budget(budgets, category, amount):
    """Set a monthly budget for a category and persist it."""
    try:
        amount = _to_positive_float(amount)
    except ValueError:
        print("Budget must be a positive number.")
        return
    budgets[category] = round(amount, 2)
    save_json(BUDGET_FILE, budgets)
    print(f"Budget for {category} set to ${amount:.2f}")

4. reports.py — CSV export

"""Report generators for the Smart Expense Tracker."""

import csv


def export_csv(expenses, filename="report.csv"):
    """Export *expenses* to a CSV file with the given *filename*."""
    if not expenses:
        print("No expenses to export.")
        return
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(
            f, fieldnames=["id", "date", "category", "description", "amount"]
        )
        writer.writeheader()
        writer.writerows(expenses)
    print(f"Exported {len(expenses)} expenses to {filename}")


def monthly_summary(expenses):
    """Return a dictionary of {month: total} for all expenses."""
    totals = {}
    for e in expenses:
        month = e["date"][:7]  # YYYY-MM
        totals[month] = totals.get(month, 0.0) + e["amount"]
    return totals

5. main.py — interactive menu

"""Entry point for the Smart Expense Tracker.

Run from the project directory:
    python main.py

Or as a module from the parent directory:
    python -m expense_tracker.main
"""

from expense_tracker.storage import load_json
from expense_tracker.operations import (
    add_expense,
    list_expenses,
    update_expense,
    delete_expense,
    summarize,
    set_budget,
    DATA_FILE,
    BUDGET_FILE,
)
from expense_tracker.reports import export_csv


def show_menu():
    print("\n=== Smart Expense Tracker ===")
    print("1. Add expense")
    print("2. List expenses")
    print("3. Update expense")
    print("4. Delete expense")
    print("5. Set category budget")
    print("6. Show summary")
    print("7. Export to CSV")
    print("8. Quit")


def get_input(prompt, required=True):
    while True:
        value = input(prompt).strip()
        if value or not required:
            return value
        print("This field is required.")


def main():
    expenses = load_json(DATA_FILE, [])
    budgets = load_json(BUDGET_FILE, {})

    while True:
        show_menu()
        choice = input("Choose an option: ").strip()

        if choice == "1":
            description = get_input("Description: ")
            category = get_input("Category: ")
            amount = get_input("Amount: ")
            add_expense(expenses, budgets, description, category, amount)

        elif choice == "2":
            category = input("Filter by category (press Enter for all): ").strip() or None
            list_expenses(expenses, category)

        elif choice == "3":
            try:
                expense_id = int(input("Expense ID to update: "))
            except ValueError:
                print("ID must be a number.")
                continue
            description = input("New description (press Enter to keep): ").strip() or None
            category = input("New category (press Enter to keep): ").strip() or None
            amount = input("New amount (press Enter to keep): ").strip() or None
            update_expense(
                expenses,
                expense_id,
                description=description,
                category=category,
                amount=amount,
            )

        elif choice == "4":
            try:
                expense_id = int(input("Expense ID to delete: "))
            except ValueError:
                print("ID must be a number.")
                continue
            delete_expense(expenses, expense_id)

        elif choice == "5":
            category = get_input("Category: ")
            amount = get_input("Budget amount: ")
            set_budget(budgets, category, amount)

        elif choice == "6":
            summarize(expenses, budgets)

        elif choice == "7":
            filename = input("Export filename (default report.csv): ").strip() or "report.csv"
            export_csv(expenses, filename)

        elif choice == "8":
            print("Goodbye!")
            break

        else:
            print("Invalid option. Please try again.")


if __name__ == "__main__":
    main()

How the code is organized

  • storage.py functions handle JSON read/write and protect against corrupt files.
  • models.py helpers create expense dictionaries and auto-generate IDs and dates.
  • operations.py contains the business logic: add, list, update, delete, summarize, and budget checks.
  • reports.py exports data to CSV using the standard library.
  • main.py runs the interactive loop and wires everything together.
