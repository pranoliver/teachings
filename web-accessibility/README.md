# Web Accessibility

A self-contained tutorial on building accessible websites and web apps. Covers semantic HTML, ARIA, keyboard navigation, screen readers, visual and motion design, testing tools, real-world case studies, and an accessible landing page capstone.

## What you'll learn

- The four WCAG principles: Perceivable, Operable, Understandable, Robust
- Semantic HTML, landmarks, and logical heading structure
- ARIA roles, states, properties, and live regions
- Full keyboard navigation and focus management
- Screen reader basics, alt text, and accessible names
- Color contrast, motion preferences, and zoom support
- Automated and manual accessibility testing
- Real-world patterns from Gov.uk, Apple, BBC, Microsoft, Stripe, and more

## Open the tutorial

Open `index.html` directly in any modern browser.

## Capstone project

Build an accessible landing page with navigation, hero section, feature cards, pricing table, newsletter form, and footer. It must pass an axe or Lighthouse audit with no critical or serious issues and work with keyboard-only input and screen readers.

## Covered topics

1. Introduction to web accessibility
2. Why accessibility matters: users, business, and law
3. Semantic HTML and landmarks
4. ARIA roles and attributes
5. Keyboard navigation
6. Screen readers
7. Visual and motion design
8. Testing and auditing
9. Real-world systems
10. Capstone: accessible landing page
