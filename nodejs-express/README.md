# Node.js & Express

A self-contained, interactive tutorial for learning server-side JavaScript with Node.js and the Express framework.

## What you'll learn

- How the Node.js runtime and event loop work
- npm, modules, and project structure
- Asynchronous JavaScript: callbacks, promises, async/await
- Express routing and middleware
- Connecting to PostgreSQL from Node.js
- Building a full CRUD REST API
- Validation, error handling, and JWT authentication
- Testing APIs with Jest and Supertest
- Deployment basics with Docker

## Structure

- `index.html` — Complete tutorial in a single file with sidebar navigation, dark mode, copyable code blocks, diagrams, and quizzes.
- `README.md` — This file.

## How to use

Open `index.html` directly in any modern web browser. No local server, build step, or internet is required after the page loads.

## Capstone

The final project is a production-style **Task API** backed by PostgreSQL. It demonstrates:

- A normalized `tasks` table
- Full CRUD endpoints with query filtering
- Input validation and structured error responses
- Environment-based configuration

## Recommended tools

- Node.js 18+ and npm
- PostgreSQL or Docker
- Postman, curl, or any HTTP client for testing
